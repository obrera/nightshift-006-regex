# Regex Tester

Interactive regex tester with live matching, highlighting, capture groups, and a quick reference cheat sheet.

🔗 **Live:** [regex.colmena.dev](https://regex.colmena.dev)

## Features

- Live match highlighting as you type
- Capture groups display
- Toggle regex flags (g, i, m, s, u)
- Match count and index display
- Quick reference cheat sheet
- Dark theme

## Stack

- TypeScript, React, Vite
- Tailwind CSS
- beeman/static-server for deployment

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
